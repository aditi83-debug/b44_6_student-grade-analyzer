# Student Result and Grade Analyzer

## About the Project
A C programming mini hackathon project that analyzes student marks in five subjects and generates individual results and a class performance report.

## Problem Statement
To develop a program that calculates total marks, percentage, grades, pass/fail status, class topper and class average.

## Program Logic
1. Input number of students.
2. Enter marks for five subjects.
3. Calculate total and percentage.
4. Check Pass/Fail status.
5. Assign grades.
6. Display topper and class average.

## Features
- Total Marks Calculation
- Percentage Calculation
- Pass/Fail Checking
- Automatic Grade Assignment
- Class Topper Identification
- Class Average Calculation

## Core C Concepts Used
- 2D Arrays
- Nested Loops
- If-Else Statements
- Variables
- scanf() and printf()

## Calculations
- Total = Sum of marks in 5 subjects
- Percentage = Total / 5.0
- Class Average = Total of percentages / Number of students

## Passing Criteria
A student must score at least 40 marks in every subject to pass.

## Grade System
| Percentage | Grade |
|---|---|
| 90 and above | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| 40–49 | E |
| Failed | F |

## Topper Calculation
The program compares students' total marks and identifies the student with the highest marks.

## Sample Output
- Total Marks: 400/500
- Percentage: 80%
- Status: PASS
- Grade: A
- Class Topper: Student 1
- Class Average: 80%

## Conclusion
This project simplifies student result processing using basic C programming concepts. It is easy to understand and can be extended with names, roll numbers and additional functions.
